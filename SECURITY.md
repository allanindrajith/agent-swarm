## Reporting a Vulnerability

We take the security of Agent Swarm seriously. Because this project is executed on user browsers as a static script and Chrome extension, security vulnerabilities primarily involve cross-site scripting (XSS), unintended DOM mutations, or manifest permission escalation.

If you believe you have found a security vulnerability:

1. **Do not create a public GitHub issue.**
2. Send an email to [84384226+allanindrajith@users.noreply.github.com](mailto:84384226+allanindrajith@users.noreply.github.com) or use GitHub Private Vulnerability Reporting if enabled.
3. Include detailed steps to reproduce the vulnerability, including browser version and sample payload.

We will acknowledge receipt within 48 hours and work with you to remediate the issue prior to public disclosure.
